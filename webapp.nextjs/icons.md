# App Icon Generation

**WARNING:** This is a draft. It has not been fully tested.

This phase focuses on creating distinctive, consistent app icons that reflect our brand identity and align with each app's purpose. The process uses AI generation with a consistent visual style across all Pavel's Dog Laboratory products.

## Visual Style Guidelines

Our icons follow a **cartoonish, friendly, and playful aesthetic** that makes complex learning approachable and fun:

- **Color Palette:** Vibrant, saturated colors with strong contrast. Primary colors with bright accents.
- **Line Style:** Bold, clean outlines with slightly rounded edges. Not too thin, not too thick - comic book style.
- **Shading:** Simple cel-shading or flat colors with minimal gradients. Light playful shadows for depth.
- **Composition:** Simple, clear focal point. Not cluttered. Easily recognizable at small sizes (down to 48px).
- **Mood:** Friendly, approachable, slightly quirky. Educational but never boring.
- **Background:** Usually solid color or simple geometric pattern. No complex textures.

## Step 1: Brainstorm Icon Concepts with AI

Use AI to generate diverse visual concepts for your icon. Provide context about your app, and the AI will suggest different compositions and subjects (the "plot" of the drawing).

### Brainstorming Prompt:

```
I need icon concept ideas for a mobile app. Please suggest 10 diverse visual concepts: 5 without characters (abstract/object-focused) and 5 with Pavel's Dog Laboratory characters.

- Icon cannot consist of many details. Descriptive scenes do not work. Leverage metaphors connecting a few objects.

APP CONTEXT:
- App name: [Your app name]
- Core purpose: [What the app does in one sentence]
- Target audience: [Who will use this app]
- Key features: [2-3 main features or unique selling points]
- Desired mood: [e.g., playful, serious, energetic, calm, trustworthy]
- Industry context: [Any conventions to follow or deliberately break]

PAVEL'S DOG LABORATORY CHARACTERS (for reference):
[Copy from characters section]

For each concept, use three sentences in the same list item:
1. Title (for reference).
2. Main subject/object (what is depicted), composition (how elements are arranged), character action (if applicable).
3. Explain metaphor if any.
```

### Example Input:

```
APP CONTEXT:
- App name: Immigrant Eyes
- Core purpose: Learn Spanish vocabulary by associating words with real-world photos from your daily life
- Target audience: English-speaking immigrants in Spanish-speaking countries
- Key features: Photo-based flashcards, spaced repetition, real-world context
- Desired mood: Adventurous, empowering, practical
- Industry context: Most language apps use flags or generic symbols; we want something more personal and experiential
```

### Output:

Review the AI's suggestions and choose 1-2 concepts that best represent your app. You can also combine elements from different suggestions or request variations.

**Document your chosen concept:**
- Selected concept: [Number and brief description]
- Any modifications: [How you'll adjust it]
- Final description: [The complete visual concept you'll use in Step 2]

## Step 2: Generate the Icon with AI

Now that you've chosen your visual concept from Step 1, use this prompt template with your preferred AI image generator (DALL-E, Midjourney, Stable Diffusion, etc.).

### Base Prompt Template:

```
Create a mobile app icon in a vibrant, cartoonish style with bold outlines and flat cel-shaded colors.

APP CONCEPT: [Your app's core purpose in one sentence]

ICON COMPOSITION:
[Paste your chosen and refined concept from Step 1. Be specific about:
- What objects/elements are shown
- How they're arranged
- If using a character: which one and what they're doing
- What visual metaphor this represents]

COLOR SCHEME:
Use our Pavel's Dog Laboratory palette:
- Primary: Vibrant Orange (#FF8533)
- Accent: Bright Yellow (#FDD835)
- Background/Highlights: Soft Cream (#FDF6E3)
- Optional: Alert Red (#EA4335) for emphasis, Dark Brown (#2B1810) for outlines

STYLE REQUIREMENTS:
- Bold, clean outlines (comic book style, ~3-4px thick)
- Vibrant, saturated colors with strong contrast
- Simple cel-shading or flat colors, minimal gradients
- Solid color background or simple geometric pattern
- Clear focal point, not cluttered
- Must be recognizable at 48px size
- Friendly and approachable aesthetic
- No text or letters in the icon
- Square format, optimized for iOS/Android app icon

TECHNICAL SPECS:
- Aspect ratio: 1:1 (square)
- Style: 2D illustration, vector art style
- No realistic textures, keep it cartoon-simple
```

## Step 3: Refine and Iterate

After generating initial versions:

1. **Test at multiple sizes:** View the icon at 1024px, 512px, 256px, 128px, and 48px
2. **Check clarity:** Is the main concept clear at the smallest size?
3. **Verify consistency:** Does it match our visual style guidelines?
4. **Get feedback:** Show to team members or potential users

### Refinement Prompt Template:

If you need to adjust the generated icon, use this follow-up prompt:

```
Modify the previous icon design with these changes:
- [Specific change 1, e.g., "Make the outlines thicker"]
- [Specific change 2, e.g., "Simplify the background to solid color"]
- [Specific change 3, e.g., "Make the character's expression more excited"]

Keep all other aspects of the design the same, maintaining the Pavel's Dog Laboratory style.
```

## Step 4: Generate Icon Sizes

Once you have your final icon design, prepare the source files and generate all required sizes.

### Prerequisites

Craft these files (1024x1024 recommended, minimum 512x512) and place them into the `public/` directory:
- `icon-source.png` - Your main icon.
- `icon-source-maskable.png` - Maskable version with safe zone padding.
- `icon-source-16.png` - Low-detail version, adapted for 16x16 (the source could be greater in size).
- `icon-source-monochrome.png` - Single color version. Only alpha channel works.

### Generate All Sizes

Run these commands from your project root:

```bash
# Generate favicon.ico from 16x16 version (source might be greater than 16x16)
ffmpeg -y -v error -i public/icon-source-16.png -vf "scale=16:16:flags=lanczos" public/favicon-16x16.png
ffmpeg -y -v error -i public/favicon-16x16.png public/favicon.ico

# Standard icons (from icon-source.png)
ffmpeg -y -v error -i public/icon-source.png -vf "scale=32:32" public/favicon-32x32.png
ffmpeg -y -v error -i public/icon-source.png -vf "scale=180:180" public/apple-touch-icon.png

ffmpeg -y -v error -i public/icon-source.png -vf "scale=192:192" public/icon-192.png
ffmpeg -y -v error -i public/icon-source.png -vf "scale=512:512" public/icon-512.png


# Maskable icon (from icon-source-maskable.png)
ffmpeg -y -v error -i public/icon-source-maskable.png -vf "scale=512:512" public/icon-maskable-512.png
```

**ffmpeg** scaling methods:
- lanczos — high-quality, sharp, good for downscaling
- bicubic — smooth, default for most cases
- bilinear — faster, softer results
- neighbor — nearest-neighbor, pixelated/crisp edges (good for pixel art)
- area — averaging, good for downscaling
- spline — similar to bicubic, slightly different curve
- gauss — Gaussian blur-based
- sinc — theoretical ideal, can ring
